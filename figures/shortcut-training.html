Shortcut training

Step-size-conditioned adapter trained against a self-distilled target from the frozen base (two_step method, paper-faithful). Training-time data flow: the adapter's architecture is shown in other figures.

    %% === Adapter (trainable, step-size-conditioned) ===
    AIN(["xt, t, c, d
step-size d highlighted"]):::data
    Adapter["Adapter (trainable)
sφ(xt, t, c, d)
step-size-conditioned
any family: output / LoRA / hypernet / hidden-state"]:::trainable
    Pred(["prediction
sφ(xt, t, c, d)"]):::data

    AIN --> Adapter
    Adapter --> Pred

    %% === Frozen base: pass A ===
    AINA(["xt, t, c
(no_grad)"]):::data
    BaseA["Frozen base
fbase(·)
pass A"]:::frozen
    VB1(["vb1"]):::data

    AINA --> BaseA --> VB1

    %% === Step forward ===
    StepFwd["xt' = xt + d · vb1"]:::compute
    VB1 --> StepFwd

    %% === Frozen base: pass B (shared weights with A) ===
    AINB(["xt', t + d, c
(no_grad)"]):::data
    BaseB["Frozen base (shared weights)
fbase(·)
pass B"]:::frozen
    VB2(["vb2"]):::data

    StepFwd --> AINB
    AINB --> BaseB --> VB2

    BaseA -. "same weights" .- BaseB

    %% === Target ===
    Target["target = ½(vb1 + vb2)
stop-grad"]:::stopgrad

    VB1 --> Target
    VB2 --> Target

    %% === Loss ===
    Loss["ℒshortcut = ‖prediction − target‖²
shortcut_direction_loss (MSE)"]:::loss

    Pred --> Loss
    Target --> Loss

    %% Gradient only on adapter
    Loss -. "gradient only on φ" .-> Adapter

Red highlights the step-size d and the timestep advance t + d: the distinguishing inputs of shortcut training. Note: the current implementation evaluates pass B at t (not t + d); the figure shows the paper-faithful behaviour and the code will be patched to match. Tracked in 20_Tickets/bug-training-shortcut-target-timestep.md. Alternative target method linear (1 base pass, target = d · fbase(xt, t, c)) is supported but not shown. The standard diffusion/flow loss against the noisy training target is added on top of ℒshortcut (not drawn). Sibling consistency heads (local_consistency, multistep_self_consistency) currently share the same detached target tensor.
