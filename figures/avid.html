The amber MLPφ node is the precise injection point at which the structural-encoder output c enters the adapter: it is projected to the time-embedding dimension and added to the time embedding before the UNet residual blocks. Existing DynamiCrafter conditioning paths (act, fs) into the time embedding are not shown. Alternative composition mask_mix (adapter also emits a gate g, with vout = (1−g)·vbase + g·δ) supported but not shown.
