Structural condition encoder

Single conditioning path consumed by every adapter family. Builds c = cond["embedding"] from a structured set of input tensors and lands at one precise injection point in each consumer. (Code: StructuredConditionEncoder in conditioning/encoders.py.)

Input condition tensor Trainable Conditioning embedding / injection point
Every adapter family in the framework spends this same c. D1 is then a study of how different adapter families consume c; D2 uses this path to inject action conditioning; D3 uses it to inject the step-size d. Only fuse_mode = "concat_mlp" and encoder = "mlp" are currently implemented per branch (encoders.py:119, 123). Alternative HyperAlign injection mode cross_attention (zero queries cross-attend to condition tokens) is supported but not shown.
