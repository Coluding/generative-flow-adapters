Shortcut training: from scratch to adapter

Pedagogical walkthrough for the advisor meeting. Shortcut models normally retrain a generative model from scratch with a self-consistency objective so it can sample in few steps. Our angle: keep the base frozen and let an adapter learn the few-step behaviour, and crucially, feed the base's local prediction into the adapter so it has a useful starting point.

1. Generative models as ODE trajectories

Both diffusion and flow matching can be sampled by integrating a learned vector field along a trajectory between two endpoints: noise on one side, data on the other. The model's job is to predict the local direction of travel at (xt, t); the sampler's job is to integrate.

The cheapest sampler is plain Euler: many small linear steps tangent to the true curve. Each step costs one model forward pass, so cutting the step count by 10× cuts inference cost by 10×. This is the lever shortcut training pulls.

Euler integration

The teal curve is the true trajectory traced by integrating the model's local direction; the dark broken line is what a standard ODE solver (Euler) actually produces: many small chords tangent to the curve. Each chord costs one base-model evaluation. Quality improves with more steps; inference cost grows linearly.

2. Shortcut models: predict the full step

The shortcut models idea (Frans et al., 2024): instead of predicting only the local direction and integrating many times, train a model that takes the step size d as input and predicts the direction of a full step of length d. At inference, one call gives you a step that would have cost many Euler steps.

The objective is self-consistency: a shortcut prediction of size 2d should equal the average of two shortcut predictions of size d taken in sequence.

s(xt, t, 2d)  ≈  ½ · s(xt, t, d)  +  ½ · s(xt+d, t+d, d)

Trained this way, the model can be queried at any step size d; large d lets you traverse the trajectory in a handful of forward passes. But: this requires retraining the entire generative model from scratch.

Shortcut sampling

The trajectory now traversed in 2 large steps instead of 8. Single-step shortcut sampling would be the diagonal arrow from x0 to x1 directly: fastest, lowest fidelity. The self-consistency loss is what teaches the model that one step of size 2d should land where two steps of size d would.

3. Our approach: adapter conditioned on step size, fed the base's local prediction

Retraining a full video diffusion model from scratch with a shortcut objective is impractical. Instead we freeze the base and put the step-size conditioning + the shortcut loss into an adapter.

The crucial design choice: the adapter receives the base model's local prediction as an additional input. That is, the velocity / noise direction the frozen base would have predicted if it had been queried in isolation, with no awareness of d. This is the same direction the base contributes to an Euler step.

Why hand the base's prediction to the adapter? Because the base already encodes a strong prior about locally where the trajectory wants to go. The adapter's job is then much narrower: starting from a good local direction, produce the step-size-consistent direction: the chord that lands on the trajectory at xt+d, not the tangent at xt.

Adapter as a chord-corrector

The base predicts the tangent at xt, which is accurate for an infinitesimal step but the wrong direction for a finite step d, because the trajectory curves. The adapter sees vbase, the step size d, and the rest of the conditioning, and learns to output the chord direction: what you'd land at if you took a single step of size d. Concretely the adapter is implementing the transformation vbase → vshortcut as a function of d.

4. Why we think this might work

  • The base already encodes a strong local prior. Asking the adapter to correct a useful starting direction is plausibly an easier learning problem than asking it to predict the chord direction from scratch.
  • At d → 0 the correct output of the adapter is exactly vbase. The architecture makes this regime trivially representable (the adapter can pass vbase through unchanged), giving us a sensible default behaviour.
  • The framework is adapter-family agnostic: the same shortcut training scheme applies whether the adapter is an output residual, a hidden-state modulation, a LoRA, or a hypernetwork. Comparing families on the shortcut speed–quality frontier is one of the planned ablations.
