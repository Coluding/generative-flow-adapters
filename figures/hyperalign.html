Zoom: Transformer Decoder internals

Each of the M zero-initialised queries is associated with exactly one LoRA target inside the frozen U-Net's attention blocks (i.e. one of to_q, to_k, to_v, or to_out.0 in a specific attention layer). The N stacked decoder layers let the queries cross-attend to the memory tokens, and the memory tokens themselves are the concatenation of (1) per-block features pooled from the frozen U-Net's input_blocks, and (2) the projected condition tokens from the structural encoder. Cross-attention is what lets each query gather the information it needs to predict its own LoRA factor.

Zoom: Factor head + reshape

The factor head is a single Linear(H → H) shared across all M decoded tokens (one per adapted LoRA module); the same weights are applied to each token independently. Its output is split along the last dimension (first r·a values, next r·b values) and reshaped into the per-module factors hyper_down and hyper_up. These are then assigned to each WrappedLoRALinear wrapper around the frozen base's attention projections via set_dynamic_hyper_factors(...). The full LoRA update is ΔW = (α/r) · (Baux · Bhyper)(Aaux · Ahyper), with Baux zero-initialised so the effective ΔW starts at zero.

a, b = auxiliary dimensions · r = LoRA rank · M = number of adapted modules · L = encoder blocks · F = video frames. Effective per-module LoRA: A = Aaux · Ahyper, B = Bhyper · Baux; Baux is zero-initialised so the effective ΔW = 0 at the start of training. Alternative injection mode cross_attention (zero queries cross-attend to condition tokens before the decoder) is supported but not shown.
